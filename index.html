Usage Notes

1. Paste a Zabbix trigger expression containing a max(/host/item,duration)=0 condition and click Convert Expression.

2. The tool auto-extracts the host, item key, and duration. Edit the fields if needed — output updates live.

3. Adjust the sensitivity multiplier (default 2.0) to control how far below baseline triggers a problem. Recovery is always fixed at 1.

4. Both expressions use baselinewma() for the weighted moving average and baselinedev() for the standard deviation over 14 days of hourly buckets.

5. The trailing and 0<>1 in the trigger is a Zabbix expression lock marker — do not remove it.

⚠ Any time() conditions in the original expression are automatically removed — Zabbix baseline functions already incorporate time-of-day context via the hourly bucket parameter "d".
